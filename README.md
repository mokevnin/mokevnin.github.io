# mokevnin.github.io

Personal page, built with [Astro](https://astro.build) and Tailwind CSS and published to GitHub Pages from `main` by `.github/workflows/deploy.yml`: <https://mokevnin.github.io>.

The content lives in `src/data/*.yaml`; the page and its components are in `src/pages` and `src/components`.

```sh
mise install     # Node and the linters pinned in mise.toml
mise run setup   # npm packages and the git hooks
mise run serve   # http://localhost:4321
```
